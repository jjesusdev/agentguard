# Portafolio — AgentGuard

## ¿Qué construí?
Daemon Linux de auditoría forense inmutable para agentes en YOLO mode. Registra cada acción de Claude Code/Cursor con trazabilidad verificable, detecta acceso a secretos y genera reportes forenses.

## Habilidades demostradas

**Seguridad Linux**
- Configuración auditd e inotify
- Principio de menor privilegio, usuarios dedicados
- Hash chain y verificación offline

**DevOps/SRE**
- Empaquetado DEB/RPM
- Rol Ansible para despliegue
- Logging estructurado JSONL
- API FastAPI + CLI Rich

**Ingeniería de IA**
- Integración Claude Code hooks PostToolUse
- Políticas YAML tipo Sigma
- Detección de anomalías comportamentales

**Calidad de software**
- Metodología 6 fases Cloudflare Security Audit
- Write isolation y validación adversarial
- Enfoque Ponytail: mínimo código efectivo con tests

## Resultados
- Arquitectura documentada con decisiones justificadas
- Metodología forense reproducible
- Guía de estudio para entrevistas
- Repo listo para demo pública

## Impacto
Cierra el gap entre sandbox y confianza para agentes autónomos. Responde a riesgos de YOLO mode destacados por AWS Sandbox Oct 2026, Splunk State of Observability 2026.
